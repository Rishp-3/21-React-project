# 🧮 React Calculator

A simple and clean Calculator web app built with **React.js** and **Vite** that performs basic arithmetic operations.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- Real-time expression and result display
- Clean and responsive UI with a modern color scheme

## 🛠️ Tech Stack

- **React.js** — Frontend UI library
- **Vite** — Fast build tool and dev server
- **JavaScript (ES6+)**
- **CSS3** — Custom grid-based button layout

## 🎨 UI Highlights

- Grid-based button layout (4 columns × 5 rows)
- Color-coded buttons:
  - 🔵 **Indigo** — Equals button
  - 🟣 **Purple** — Operator buttons (+, −, ×, ÷)
  - ⬜ **Grey** — Number buttons
- Expression shown above, result shown below in the display

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or above)
- npm

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/Rishp-3/Project3.git
```

2. **Go to the Calculator folder**

```bash
cd Project3/Calculater
```

3. **Install dependencies**

```bash
npm install
```

4. **Run the app**

```bash
npm run dev
```

5. Open your browser and go to `http://localhost:5173`
