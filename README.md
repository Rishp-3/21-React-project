## ✨ Features

- ⚛️ **React 18 + Vite 5** — bleeding-edge toolchain with sub-100ms HMR
- 🔁 **Full Hook Coverage** — `useState`, `useEffect`, `useRef`, `useCallback`, `useReducer` — all demonstrated in real context
- 📡 **Real API Integration** — live data fetching with async/await patterns (Weather App, Movie Search)
- 💾 **Persistent State** — Local Storage integration across multiple projects
- 🎨 **Pixel-Perfect Layouts** — CSS Grid & Flexbox used intentionally, not incidentally
- 🔒 **Controlled Forms** — Validation, regex patterns, and UX-first input handling
- 🧩 **Isolated Architecture** — Each project is fully self-contained; zero shared dependencies
- ⚡ **One-Command Startup** — `npm i && npm run dev` — every single time, no exceptions

## 📦 Installation

### Prerequisites

```bash
node --version   # >= 18.0.0 required
npm --version    # >= 9.0.0 required
```

### Step 1 — Clone the Repository

```bash
git clone https://github.com/Rishp-3/Project3.git
cd Project3
```

### Step 2 — Navigate to Any Project

```bash
cd Calculater   # Replace with: ToDoList, DigitalClock, WeatherApp, etc.
```

### Step 3 — Install & Run

```bash
npm install
npm run dev
```

### Step 4 — Open in Browser

```
http://localhost:5173
```

> 💡 **Every project follows the exact same 3 steps** — `cd`, `npm install`, `npm run dev`. No exceptions.

## 🤝 Contributing

All contributions are welcome! Here's how to get started:

```bash
# 1. Fork this repository on GitHub

# 2. Clone your fork
git clone https://github.com/YOUR_USERNAME/Project3.git

# 3. Create a feature branch
git checkout -b feat/improve-weather-app

# 4. Make your changes, then commit
git commit -m "feat(WeatherApp): add 5-day forecast panel"

# 5. Push and open a Pull Request
git push origin feat/improve-weather-app
```

**Before submitting a PR:**
- Keep each project self-contained — no shared logic between folders
- Follow the existing file/folder structure shown above
- Open an issue first for major feature changes
- PRs with tests get reviewed & merged faster 🚀
