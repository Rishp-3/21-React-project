## ✨ Features

- ⚛️ **React 18 + Vite 5** — bleeding-edge toolchain with sub-100ms HMR
- 🔁 **Full Hook Coverage** — `useState`, `useEffect`, `useRef`, `useCallback`, `useReducer` — all demonstrated in context
- 📡 **Real API Integration** — live data fetching with async/await patterns (Weather, Movies)
- 💾 **Persistent State** — Local Storage integration across multiple projects
- 🎨 **Pixel-Perfect Layouts** — CSS Grid & Flexbox used intentionally, not incidentally
- 🔒 **Controlled Forms** — Validation, regex, and UX-first input handling
- 🧩 **Isolated Architecture** — Each project is fully self-contained; no shared dependencies
- ⚡ **One-Command Startup** — `npm i && npm run dev` — that's it, every time

## 📦 Installation

### Prerequisites

```bash
node --version   # >= 18.0.0
npm --version    # >= 9.0.0
```

### Clone the Repository

```bash
git clone https://github.com/Rishp-3/Project3.git
cd Project3
```

### Run Any Project

Every single project uses the same three commands — no exceptions:

```bash
# Step 1: Navigate to the project
cd Calculater   # Replace with any project folder name

# Step 2: Install dependencies
npm install

# Step 3: Launch dev server
npm run dev
```

### Open in Browser

```
http://localhost:5173
```

> 💡 **Pro tip:** Vite supports `--port` flag if 5173 is busy — `npm run dev -- --port 3000`

## 🛠️ Usage

<details>
<summary><b>🧮 Example: Running the Calculator</b></summary>

```bash
cd Calculater
npm install
npm run dev
# → http://localhost:5173
```

</details>

<details>
<summary><b>🌤️ Example: Running the Weather App (requires API key)</b></summary>

```bash
cd WeatherApp
cp .env.example .env         # Create your env file
# Add your OpenWeatherMap API key to .env:
# VITE_WEATHER_API_KEY=your_key_here

npm install
npm run dev
```

</details>

<details>
<summary><b>🎬 Example: Running the Movie Search (requires API key)</b></summary>

```bash
cd MovieSearch
cp .env.example .env
# Add your OMDB API key:
# VITE_MOVIE_API_KEY=your_key_here

npm install
npm run dev
```

</details>

### Build for Production

```bash
npm run build        # Outputs to /dist
npm run preview      # Preview production build locally
```

## 🤝 Contributing

Contributions are welcome and appreciated. Here's how to get involved:

```bash
# 1. Fork the repository
# 2. Create your feature branch
git checkout -b feat/improve-weather-app

# 3. Commit with a conventional commit message
git commit -m "feat(WeatherApp): add 5-day forecast view"

# 4. Push and open a PR
git push origin feat/improve-weather-app
```

**Guidelines:**
- Keep each project self-contained — no shared logic between folders
- Follow the existing file structure (see [Folder Structure](#-folder-structure))
- Open an issue first for major changes so we can align on scope
- PRs that add tests get merged faster 🚀
