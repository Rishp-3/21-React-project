## 🚀 Getting Started

</div>

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Rishp-3/Project3.git
cd Project3
```

### 2️⃣ Open Any Project
```bash
cd Calculater   # or ToDoList, DigitalClock, etc.
```

### 3️⃣ Install & Run
```bash
npm install
npm run dev
```

### 4️⃣ Open in Browser
```
http://localhost:5173
```

> 💡 **Every project follows the same 3 steps** — `cd`, `npm install`, `npm run dev`
